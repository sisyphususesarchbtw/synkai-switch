## Required project story

Problem: agent-written fixes can look green without demonstrating the reported behavior is fixed.
Workflow: person agrees on behavior -> verifier freezes check -> fixer proposes patch -> independent before/after run -> person reviews evidence.
Role of Switch: real room context, addressing, clarification, agent handoffs and evidence return. It is central to collaboration.
