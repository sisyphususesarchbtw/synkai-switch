# Synkai artwork
LOGO.png is an unchanged copy of the participant-supplied original in the parent Hackathon folder. The participant supplied the name and creative direction. Do not claim a production method or provenance that has not been established.

Assessment: 8.5/10 as a large brand illustration; 5/10 as a compact application logo. Strengths: coherent monochrome engraving, cooperating figures, a classical wordmark and collective orbital geometry. Limits: fine lines/stippling collapse at icon size; orbital/star motifs are familiar; tiny construction marks are decoration.

Keep this original. Use sparingly on introduction/about/empty-room screens, and use a text wordmark in the working UI. A separate compact mark can come later without overwriting the artwork. No editing, extraction or new favicon has been performed.
