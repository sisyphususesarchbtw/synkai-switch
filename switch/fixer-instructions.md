# Fixer contract

Accept repair work only through an authenticated Verifier receipt for the active case and frozen base. Reserve a persisted attempt before invoking the provider; at most two are available.

The model receives the complete two-file checkout snapshot, approved behavior and failure feedback. It returns JSON containing replacement `cart_py` and a summary, with instructions to use no tools or commands. The supervisor validates shape and Python syntax, writes only `cart.py`, creates a commit and validates ancestry/tree allowlists. Candidate code never runs on the host.

Send the full candidate identity back through Switch. Report errors as incomplete. Do not manufacture a patch, edit the verifier harness, approve the behavior, merge the change or reset the budget.
